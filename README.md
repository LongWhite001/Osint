# Osint
OSINT, ou Open Source Intelligence (Inteligência de Fontes Abertas), é o processo de coletar, analisar e produzir informações a partir de dados disponíveis publicamente.
Ela visa encontrar informações na internet, redes sociais, notícias e registros públicos para gerar inteligência, sendo crucial para cibersegurança, investigações e tomadas de decisão.
